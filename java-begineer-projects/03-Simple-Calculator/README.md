# Smart Calculator

A simple Java console application that performs basic arithmetic operations based on the user's choice.

## Features

- Takes two numbers as input
- Displays a menu of operations
- Performs:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Displays the calculated result

## Concepts Used

- Java
- Scanner
- Variables
- Arithmetic Operators
- Switch Statement
- Console Input & Output

## Sample Output

```
===============================
      SMART CALCULATOR
===============================
Enter First Number: 20
Enter Second Number: 10

1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter Operation: 1

Addition = 30
```
