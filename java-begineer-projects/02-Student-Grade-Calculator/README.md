# Student Grade Calculator

A simple Java console application that accepts a student's marks in five subjects, calculates the total and percentage, and displays a formatted report card.

## Features

- Takes the student's name as input
- Accepts marks for five subjects
- Calculates total marks
- Calculates percentage
- Displays a neat report card

## Concepts Used

- Java
- Scanner
- Variables
- Data Types
- Arithmetic Operators
- Console Input & Output

## Sample Output

```
=================================
       STUDENT REPORT CARD
=================================
Name         : Irfan

Physics      : 92
Chemistry    : 88
Maths        : 95
English      : 84
Computer     : 90

-------------------------------
Total        : 449
Percentage   : 89.8%
=================================
```
