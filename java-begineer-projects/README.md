# Student Profile

A simple Java project that takes student details from the user and displays them in a clean and formatted profile.

## Features

- Takes user input using Scanner
- Stores student information
- Displays the details in a formatted output

## Concepts Used

- Java
- Scanner
- Variables
- Data Types
- User Input
- Console Output

## Sample Output

```
=================================
        STUDENT PROFILE
=================================
Name         : Irfan
Age          : 19
College      : VIT Bhopal
Branch       : CSE
Roll Number  : 23BCE1001
CGPA         : 8.75
=================================
```

## What I Learned

- Taking user input using `Scanner`
- Difference between `nextInt()` and `nextLine()`
- Choosing the correct data type (`String`, `int`, `double`)
- Formatting console output
